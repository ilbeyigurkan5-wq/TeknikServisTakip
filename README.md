*# Teknik Servis Takip Otomasyonu*



*Bu proje, C# WinForms ve SQL Server kullanılarak geliştirilmiş bir teknik servis takip uygulamasıdır.*



*## Projenin Amacı*



*Müşteri, cihaz, servis kaydı ve ödeme işlemlerini tek bir sistem üzerinden takip etmek için hazırlanmıştır.*



*## Kullanılan Teknolojiler*



*- C#*

*- WinForms*

*- SQL Server*

*- ADO.NET*

*- Repository-Service-Model yapısı*



*## Özellikler*



*- Kullanıcı girişi*

*- Müşteri ekleme, güncelleme, silme ve arama*

*- Cihaz ekleme, güncelleme, silme ve arama*

*- Müşteriye bağlı cihaz listeleme*

*- Servis kaydı oluşturma*

*- Servis durum takibi*

*- Cihaz teslim işlemi*

*- Ödeme alma*

*- Toplam ödenen ve kalan tutar hesaplama*

*- SQL JOIN sorguları ile ilişkili veri listeleme*



*## Veritabanı Tabloları*



*- Kullanicilar*

*- Musteriler*

*- Cihazlar*

*- ServisKayitlari*

*- Odemeler*



*## Proje Yapısı*



*- Models*

*- Repositories*

*- Services*

*- Forms*



*## Not*



*Bu proje öğrenme amacıyla geliştirilmiştir. Katmanlı yapı, SQL ilişkileri ve temel iş kuralları pratiği yapılmıştır.*
